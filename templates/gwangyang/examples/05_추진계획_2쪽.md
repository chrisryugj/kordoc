# kordoc 광양시 서식 추가지원 추진계획

```gwangyang
{"type":"staff-header","title":"담당자","date":"2026. 10. 26.","staff":[{"role":"○○과장","name":"미정","phone":"미정"},{"role":"○○팀장","name":"미정","phone":"미정"}]}
```

> 광양시 보고서 서식을 kordoc의 재사용 부품으로 정리하고 기존 피팅 기능과 연계하여 문서 작성의 일관성과 활용 편의를 높이고자 함

## 추진 배경 및 현황

○ 제목‧번호칸‧상자‧표의 반복 수작업을 줄이고 기관 서식의 일관성 확보

○ 광양시 서식 14종 정리 및 기존 피팅 연계 완료, 실제 업무 문서로 활용 검증 추진

## 추가지원 내용

| 구분 | 주요 지원내용 | 적용 기준 |
|---|---|---|
| 제목 체계 | 대제목 띠‧번호 소제목‧붙임 머리표 | 1안‧2안 선택 적용 |
| 설명 영역 | 흰‧보라 설명상자, 둥근 상자 2종 | 문안 길이에 따른 높이 조정 |
| 문서 골격 | 담당자 머리표‧기관 표지‧표 제목 | 부서‧담당자 정보 입력 |
| 본문표 | 기관별 테두리‧머리행‧병합 구간 | 공통 표 생성기 활용 |
| 자동 피팅 | 장평‧자간‧줄바꿈 및 표 크기 계산 | 서식 유지, 내용 삭제 금지 |

## 추진 방법 및 일정

○ 문서종류‧기관 스타일 선택 후 마크다운 원고 입력


○ kordoc 코드가 서식 적용과 피팅을 처리하고 HWPX 문서를 생성


○ 한글 PDF에서 잘림‧겹침‧쪽넘김 확인 후 검증 결과 보관

| 단계 | 추진사항 | 완료 기준 |
|---|---|---|
| 1단계 | 14종 목록‧입력 규칙‧사용 예제 정리 | 같은 원고의 재생성 확인 |
| 2단계 | 보고서‧계획서 시범 작성 및 장문 검증 | 서식‧내용 보존 확인 |
| 3단계 | 사용자 의견 반영 및 적용 범위 보완 | 담당자 검토 완료 |
| 4단계 | 변경내역 정리 및 PR 제출 검토 | 검증 자료‧공개 범위 확정 |

※ 세부 일정과 담당부서는 협의 후 확정하며, 현재는 로컬 작성‧검증 단계임.

## 운영 기준 및 향후계획

○ 제목 띠‧번호칸‧색‧테두리‧로고를 유지하고 장평‧자간‧높이만 필요한 범위에서 조정


○ 한 쪽을 넘는 둥근 상자는 문단을 나누어 입력하고 임의 축소‧누락 방지


○ 원본 보고서와 생성 샘플을 구분하여 보관하고 외부 공개 전 포함 자료 점검

```gwangyang
{"type":"box","variant":"purple","title":"향후 조치","body":["◦ 본 추진계획을 2쪽 작성 사례로 검토하고 실제 업무 문안으로 추가 시험","◦ 사용법과 검증 결과를 정리한 후 로컬 적용 범위 및 PR 제출 여부 결정"]}
```
