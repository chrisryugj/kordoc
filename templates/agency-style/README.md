# 새 기관 스타일 시작하기

[등록 규격](../../docs/agency-style-registration.md)을 읽고 [광양시 style.json](../gwangyang/style.json)을 첫 사례로 참조한다. 새 기관은 별도 폴더에 등록하며 광양시 원본 자산이나 기관명을 자동 복제하지 않는다.

작성 지침에는 다음 항목을 반드시 채운다.

1. 적용 문서 종류와 독자, 사용할 기본 변형
2. 제목·요지·장·본문 항목의 역할과 입력 문법
3. `ㅇ (항목명) 설명`을 쓸 조건 및 쓰지 않을 조건
4. 표·설명상자·붙임·표지 선택 기준
5. 글꼴·문장부호·로고·담당자 정보 처리 기준
6. 작성 모델과 생성 엔진의 책임, 목표 분량을 넘을 때 처리
7. 좋은 원고 예시, 피해야 할 예시, 실행 가능한 샘플 경로

복사해서 시작할 실제 지침: [광양시 작성 지침](../gwangyang/writing-guide.md). 모델에 기관의 작성 지침과 해당 입력 스키마를 제공한 뒤 원고만 작성하게 한다. 등록 JSON을 프롬프트에 넣는 것만으로 엔진 기능이 생기지는 않는다.
