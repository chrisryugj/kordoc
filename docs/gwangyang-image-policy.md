# 광양시 이미지 이용조건과 배포 정책

확인일: 2026-10-27. 사용자 요청에 따라 기관 이미지는 제외하고 기존 자리를 유지한다.

## 공식 표시 확인

아래 공식 페이지의 담당자 정보 영역(`manager_info > mark_box`)에는 모두 `/ecms_resource/img/kogl/size1/img_opentype04.png`가 있다. 대체텍스트는 공공누리 제4유형의 출처표시·비상업적 이용·변경금지 조건을 안내한다. 검색 도구의 본문 추출에서는 이 표시가 누락됐으나 원본 HTML에서 확인했다.

- [Sunshine 브랜드](https://gwangyang.go.kr/menu.es?mid=a11303010000)
- [비전](https://gwangyang.go.kr/menu.es?mid=a11303030000)
- [휘장(심볼마크)](https://gwangyang.go.kr/menu.es?mid=a11303040000)
- [광양시 저작권보호정책](https://gwangyang.go.kr/menu.es?mid=a11505010000): 제4유형은 출처표시·상업적 이용금지·변경금지이며, 표시 없는 자료는 사전 협의를 안내한다.

홈페이지의 표시를 확인한 것으로 별도 사용 승인을 받았다는 뜻은 아니다. 다운로드 파일별 추가 조건이나 보고서에서 추출한 제목 장식의 자유배포 근거는 확인하지 않았다. 상징물 담당 연락처는 해당 페이지에 안내된 061-797-2384, 공공저작물 실무담당은 저작권 정책에 안내된 061-797-2734다.

## 구현

기관 로고 3개와 제목 장식 2개의 base64 소스 파일을 제거했다. 생성 HWPX에 이 이미지들을 넣지 않는다. 제목 띠의 상하 셀 높이, 머리표 왼쪽 로고 칸, 기관 표지 위쪽 두 로고 칸·아래쪽 상징 칸은 빈 자리로 유지한다. 과장·팀장 두 줄 및 날짜·본문·표의 서식은 유지한다. 자리에는 안내문구나 대체 로고를 그리지 않는다.

필요하면 사용자가 해당 이용조건을 확인한 이미지를 한글에서 직접 넣는다. 자동 다운로드나 새 이미지 입력 API는 이 변경에 포함하지 않는다. 원본 문서와 이미지를 재라이선스하지 않으며 등록 manifest의 원천 재배포 상태는 excluded다.

이 제거는 현재 소스와 배포 결과에 적용된다. 과거 PR 커밋에 있던 자산의 Git 이력을 삭제한 것은 아니다.
