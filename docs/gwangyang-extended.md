# 광양시 민선9기 확장 부품

광양시 1안(`reportFrame: "gwangyang-1"`)의 `gwangyang` JSON 코드블록으로 사용한다. CLI와 MCP에서도 같은 마크다운을 전달한다. `institution-cover` 사용 시 기존 자동 표지는 `cover:false`로 끈다. 코드 예시는 `templates/gwangyang/examples/`의 원고에 있다.

| type | 입력 | 배치·원본 |
|---|---|---|
| `staff-header` | `title`, `date`, `staff:[{role,name,phone}]` | H1 앞에 한 번 배치. 로고 왼쪽, 날짜+담당자 표 오른쪽. D08 규제샌드박스 보고전 |
| `institution-cover` | `title`, `subtitle?`, `date?`, `dept?`, `documentNumber?`, `retention?`, `disclosure?`, `approvers?`, `body` | 문서 맨 앞 별도 표지. D13 전기자전거 기본계획 |
| `rounded-box` | `title`, `variant: "plain" 또는 "tab"`, `body` | 본문 위치에 편집 가능한 한글 도형. D13/D24 착수보고회 결과 보고 |

```gwangyang
{"type":"staff-header","title":"담당자","date":"2026. 10. 26.","staff":[{"role":"담당 팀장","name":"홍길동","phone":"0000"}]}
```

```gwangyang
{"type":"rounded-box","title":"회의 개요","variant":"tab","body":["□ 일시: 2026. 10. 26.(월)","□ 내용: 보고서 서식 검토"]}
```

- `staff-header.title`은 블록 식별용이며 지면에는 날짜·담당자만 표시한다. `rounded-box.title`은 `tab`에서 표시한다.
- 기관 표지 상단은 Sunshine + 민선9기 비전 로고, 하단은 시 상징과 광양시·입력 부서명이다. 기존 감동시대 슬로건은 포함하지 않는다.
- 기관 표지에는 실명이 없는 빈 결재칸을 만든다. `approvers`로 직위를 지정하며 1~6칸을 지원한다.
- 둥근 상자는 `hp:rect` + `hp:drawText`로 만든다. 본문은 휴먼명조 15pt, 제목 탭은 맑은 고딕 14pt 기준이다. 본문 굵게 표기를 지원한다.
- 원본 모서리 비율 3, 선 #004B8E·0.3mm, 제목 탭 비율 20·배경 #DFE6F7을 적용한다. 폭은 본문폭에서 계산한다.
- 도형은 페이지 사이에서 나뉘지 않는다. 높이 한도를 넘으면 오류로 알려 여러 상자로 나누도록 한다. 표지는 요약 높이를 더 엄격하게 제한한다. 제목 탭은 기존 피팅 후 필요하면 여러 줄로 높이를 늘린다.
- 생성 샘플은 A4 여백 위/아래 15mm, 좌/우 20mm에서 한컴 PDF 출력으로 검증했다. 다른 용지·매우 긴 메타정보는 별도 지면 확인이 필요하다.

## 원천과 자산

사용자 로컬 원본: 감동시대추진단 보고서 모음의 D08(20240905 규제샌드박스), D13(240729 전기자전거 기본계획), D24(착수보고회 결과 보고). 원본을 덮어쓰지 않고 구조·비율을 코드로 구현했다.

민선9기 로고: 기존 검증 보고전 `바이브회의록_국장보고용_V2.hwpx`의 `BinData/image2.bmp`, 문구 **대한민국 산업수도 광양**. 사용자가 지정한 기존 보고전의 로고를 사용한다. 기존 로고 픽셀을 PNG로 무손실 변환하여 임베드한다. 임의로 새로 그린 로고가 아니다.

Sunshine과 시 상징은 D13의 `image4.jpg`, `image6.png`. 코드 자산마다 SHA256을 기록했다. 보고서 본문·사진·기존 슬로건은 코드에 임베드하지 않았다.

## 검증

- 담당자/표지 위치, 입력 오류, 중복 방지, 편집 가능한 도형 텍스트의 재파싱, XML 구조 검사: `tests/gongmun-gwangyang-extended.test.ts`.
- 한글 COM 실제 PDF: 머리표 1쪽 / 표지+본문 2쪽 / 두 종류 둥근 상자 1쪽.
- 현재 로컬 확장 구현이며 패키지 게시·PR 반영 상태와는 별개다.

임베드된 기관 로고·장식은 소프트웨어 코드와 별개의 원천 자산이다. 제공 사실만으로 MIT 재라이선스나 기관 공식 승인을 주장하지 않는다. 공개 병합 전 재배포 근거 확인이 필요하며 등록 자료에 not-reviewed로 표시한다.
