# 기존 기관 서식 회귀 수정·비교 검증

2026-10-27, PR #173.

## 원인과 수정

`applySchemeOverrides`가 모든 `g.agency`에 대해 본문 기본값과 같은 단계 크기까지 덮어썼다. 경찰청 report/plan의 17·15·14pt가 15·15·15pt로 바뀌었다. 해당 보정은 `LOCAL_AGENCY_STYLES`에 직접 등록된 기관에만 적용한다. 명시한 `bodyPt`의 기존 우선순위도 유지한다.

## 기준과 비교 방법

- 기준 main: `3d6a4673bc9fbc68c353054593a6a570c4f66093`.
- 같은 main을 PR 브랜치에 병합한 후 비교했다.
- 두 엔진의 시간을 동일한 값으로 고정해 ZIP 작성시각 차이를 방지했다. 생성된 HWPX를 수정·정규화하지 않고 바이트 전체와 SHA-256을 비교했다. 경고 배열도 비교했다.
- 짧은 위계·본문표 문안과 긴 문안·HTML 병합표 문안을 사용했다.
- 기본값, 명시 bodyPt 14, bodyPt 15 + 본문 글꼴 + 단계별 pt 지정의 세 옵션 조합을 사용했다.

| 비교 범위 | 건수 | 결과 |
|---|---:|---|
| 기존 52개 기관 + 공통 × report/plan/press/ministry/gaejosik × 2문안 × 3옵션 | 1,590 | 전부 바이트 동일 |
| 기관 미지정 일반 프리셋 9종 × 2문안 × 3옵션 | 54 | 전부 바이트 동일 |
| 위 1,644건의 경고 배열 | 1,644 | 전부 동일 |
| 광양시 샘플 5종 × 기본값/bodyPt 14/autoFit false, 수정 전후 비교 | 15 | 전부 바이트 동일 |

수정 전 156건의 기본 비교에서는 이 문안 기준 84건의 차이가 재현됐다. 관리자의 다른 문안에서 나온 88건과 모수가 같더라도 문안은 동일하지 않다. 수정 후에는 더 넓은 1,644건에서 차이가 없었다.

광양시 수정 전 기준은 `27842ad0e7edd8400f0ed300dd9c51c020f82a10`이다. 경찰청 17·15·14pt 및 광양시 16·15·15pt와 명시 크기 우선순위를 확인하는 회귀 테스트를 추가했다. 새 테스트를 수정 전 코드에 실행하면 실제로 실패한다.

## 재현

기준 커밋의 별도 체크아웃과 의존성을 준비한 뒤 PR 체크아웃에서 실행한다.

```sh
node --import tsx scripts/compare-agency-regression.mjs /path/to/main-checkout output/agency-comparison
# 관리자가 지적한 52개 기관 × report/plan/press 기본 비교만 실행
node --import tsx scripts/compare-agency-regression.mjs /path/to/main-checkout output/agency-quick --quick
```

`comparison.json`에 건별 해시·동일 여부·경고 동일 여부가 기록된다. 다르면 두 HWPX 파일을 남기고 종료 코드 1을 반환한다. 기준 기관 수가 52개가 아니면 비교 범위를 조용히 바꾸지 않고 오류로 알린다.

## 검사 범위

- 타입 검사·ESM/CJS/타입 선언 빌드 통과.
- 기관·공문서 생성 관련 테스트 275개 통과.
- 전체 테스트: 4,581개 중 4,542개 통과, 24개 실패, 15개 생략. 전체 통과로 간주하지 않는다.
- 기관 이미지의 재배포 조건은 이 수정과 별개로 검토가 남아 있다.
