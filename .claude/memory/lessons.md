# Lessons Learned

| 상황 | 실수 | 교훈 | 방지 규칙 |
|------|------|------|-----------|
| 균등배분 감지 | `isShortKorean`에 2자 한글 포함 → "중동 사태 대응" 같은 정상 2자 단어를 균등배분으로 오판해서 공백 삭제 | 균등배분은 **1자 개별 배치**만 해당. 2자 단어는 단어 간 공백이지 균등배분 아님 | `detectEvenSpacedItems`의 isShortKorean은 `/^[가-힣]{1}$/`만 |
| 한글 갭 기준 | 0.35→0.5로 올렸다가 단어 간 공백이 사라짐 (공백누락 32→51 악화) | 갭 기준 변경은 균등배분과 단어 공백의 **트레이드오프** — 균등배분은 좌표 기반으로 별도 처리하고 갭 기준은 보수적으로 유지 | 갭 기준 변경 전 반드시 공백누락 카운트 확인 |
| pdfplumber 과대평가 | pdfplumber로 교체하면 다 해결될 거라고 잘못 판단 | pdfplumber도 pdfminer.six 기반으로 **동일한 균등배분/CJK 공백 문제** 있음. 한국 공문서 특화 기능은 kordoc이 유일 | 외부 라이브러리 교체 권고 전 해당 라이브러리의 CJK/한국어 이슈 실제 조사 필수 |
| 정규식 후처리 vs 좌표 기반 | 정규식으로 균등배분을 처리하려다 모든 경우의 수를 커버 못 함 | **근본 해결은 좌표 기반** — `normalizeItems`에서 TextItem 분해 후 `detectEvenSpacedItems`로 처리. 정규식은 안전망으로만 | 텍스트 후처리보다 아이템 좌표 단계에서 처리 우선 |
| PDF 코퍼스 수집 (2026-07-02) | korea.kr RSS 폐지를 보고 "크롤러 재구축 필요, 다음 세션 보류"로 프레이밍 — 특정 사이트 크롤에 갇힘 | 목표는 "실PDF 20건+"이지 특정 소스가 아님. **검색엔진이 이미 정부 PDF를 인덱싱**해놨음 — `filetype:pdf site:go.kr` 5회 검색으로 43개 직링크, 42건 수집 완료 (사용자 교정) | 코퍼스/샘플 수집이 막히면 크롤러 만들기 전에 검색엔진 filetype/site 연산자부터 시도 |
| README 수치 갱신 (2026-09-29) | 벤치 수치를 올릴 때마다 README 에 채점 기준·재현·예외를 한 문단에 덧붙이고(채점 기준 1,248자 한 줄), 기능 표 칸에 서너 문장, "최근 변경"에 7개 버전 CHANGELOG 중복 — 사용자: "더 읽기 싫고 지저분하게 만들어논 거 같은데" | README 는 한 줄 요약 + 링크. 세부(채점 기준·재현·옵션별 수치)는 docs/benchmarks.md, 변경 이력은 CHANGELOG 로. 수치만 바꿀 땐 그 숫자만 고친다 | README 에 문장을 더하기 전에 "이게 docs/CHANGELOG 로 가야 하나" 먼저 판단 · 250자 넘는 줄이 새로 생기면 쪼개거나 옮긴다 · 같은 수치가 README 여러 곳에 있으면 전부 같이 고친다(78행 96.7% 방치 사례) |
| 압축 뒤 보고 언어 (2026-10-09) | 컨텍스트 압축 뒤 몇 시간 동안 진행 보고·도구 설명을 영어로 씀 — 사용자: "말좀 한글로해" (09-29 에 이어 재발) | 영어 커밋 메시지·코드 주석을 쓴 직후 보고문이 그 언어를 따라간다. 사용자에게 보이는 글은 언제나 한국어 반말 | 압축 직후 첫 응답과 커밋 직후 보고문의 언어를 확인 · 도구 호출 description 도 한국어 |
| 공용 OCR 줄 묶음 (2026-10-09) | ODL(그림 영역)만 보고 `groupOcrLines`·`ocrItemsToBlocks` 규칙을 확정 → 스캔 OCR 3쪽·열화 OCR 6조건이 조용히 떨어짐 | 그림 영역 OCR 과 쪽 전체 OCR 은 같은 함수를 쓴다. 규칙이 막으려던 잡음은 기하가 아니라 인식 신뢰도로 갈렸다 | OCR 줄 처리를 고치면 odl·ocr·robust 를 다 돌린다 |
| 글자 주머니 지표 (2026-10-09) | 단 가르기 수정 뒤 kats PDF 커버리지가 기준값으로 돌아와 고쳐진 줄 알았는데, 기본 옵션 출력에선 그 쪽 본문이 6열 가짜 표가 됨(글 벤치 재현율 0.00003 하락으로만 드러남) | 커버리지는 글자 주머니라 순서·구조가 망가져도 돌아온다 | 하락을 고친 문서는 기본 옵션 출력을 직접 보고, 다른 벤치의 같은 문서 지표도 확인 |
| 단건 벤치와 묶음 측정 (2026-10-09) | 묶음 측정(suite) 중인 워크트리에서 단건 표 벤치를 돌려 그 루트의 `bench/out/pdf-table.json` 을 덮음 | suite 는 자식이 끝난 뒤 그 루트 `bench/out/` 산출물을 복사한다 — 자식이 죽으면 단건 결과를 전체로 오인 | 단건 실험은 측정 안 하는 워크트리에서, 측정 결과는 모수(쌍 수)부터 확인 |
